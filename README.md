PROJECT OVERVIEW

Team Task Manager is a full-stack web application built to help teams organize projects, assign tasks, and monitor progress in a structured and secure way. The system supports role-based access control, ensuring that administrators and team members have clearly defined permissions within the application.

The application allows users to create projects, manage team members, assign tasks, and track task status through a centralized dashboard. Each task includes details such as description, assigned user, status, and due date, enabling efficient workflow management.

Security and scalability are key considerations in the design. The system uses JWT-based authentication, password hashing, and protected API routes to ensure secure access. The architecture follows clean coding practices, making it suitable for real-world applications and future enhancements.

Overall, the project demonstrates core full-stack development concepts including RESTful API design, database relationships, authentication, authorization, and responsive frontend integration.
